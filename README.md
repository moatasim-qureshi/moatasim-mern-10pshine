NoteIt
NoteIt is a smart and intuitive note-taking application that allows users to create, edit, and organize their notes efficiently. In addition to standard note management, it includes advanced features like a personal chatbot, profile verification, and secure password management.

Features

-- Create, Edit, Delete Notes – Manage your notes effortlessly.
-- Organize Notes – Categorize or tag notes for easy retrieval.
-- Search Notes – Quickly find notes by keywords.
-- Responsive UI – Works on desktops, tablets, and mobile devices.
-- Chatbot Integration – A built-in assistant to help with notes or answer queries.
-- Profile Verification – Verification code sent to email when changing password to ensure account security.
-- Testing
    Frontend tested with Jest.
    Backend tested with Mocha & Chai.
-- Code Quality – Project analyzed using SonarQube for maintaining clean, bug-free code.

To Start the project:
1) Change environment variables
2) Run initDB.js to make all the tables for database
3) Go to frontend and run "npm run dev"
4) Open another terminal
5) Go to backend and run "node server.js"
6) Your application will run
7) Dont forget to run "npm install" first.
